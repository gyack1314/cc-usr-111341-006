# 方法论：混频、参差发布下的实时估计

本文说明模块如何用“决策日真正可得”的资料估计尚未发布的季度指标，以及
为什么这样设计、有哪些识别约束、哪里会降级、失败如何暴露。

---

## 1. 问题与硬约束

目标是季度指标（如季度增加值），但它比月度指标晚约一个月才首次发布，
且发布后还会被多次修订。三个必须遵守的约束：

1. **时点可见性**：决策日 `d` 只能看到 `released <= d` 的版本。当天发布
   视为当天可得（`--visibility exclusive` 可改成严格早于决策日）。
2. **修订不可回填**：同一参考期可以多次发布。回测不能把后来修订后的
   数值当成当时已知信息；评估用哪个版本必须事先冻结。
3. **参差发布不补全**：观测期结束不等于资料已发布。缺报、暂未发布与
   已报告为零必须分开保留，不能先把面板补成完整矩阵再建模。

代码里这三个约束分别落实在 `vintages.py`（可见性与状态）、`model.py`
（只用训练截点可见版本拟合参数）与 `evaluation.py`（冻结口径）中。

---

## 2. 资料模型

### 2.1 参考期与日历

- 月度：`YYYY-MM`；季度：`YYYY-Qn`。
- 参考期有真实日历边界（`period_end`），月末、闰年与跨季度都按日历处理。
- **提前期**统一用“决策日距目标参考期结束日的日历天数”：正数为提前，
  负数为期末之后。报告分组为 `lead>30`、`lead1-30`、`after0-30`、
  `after31-60`、`after61+`。

### 2.2 每个资料单元的状态

对每个 `(指标, 参考期)`，决策日快照保留五类状态之一：

| 状态 | 含义 | 是否进入模型 |
| --- | --- | --- |
| `observed` | 决策日已有可见发布，值为当时版本 | 是 |
| `reported_zero` | 决策日已有可见发布，值为 0 | 是（与缺报分开） |
| `pending` | 参考期已结束，但决策日尚无可见发布 | 否，可外推 |
| `future` | 参考期尚未结束 | 否 |
| `missing` | 超过宽限期仍无任何发布记录 | 否，并触发提示 |

`pending`/`missing` 的区分只看“参考期结束 + 该指标首发布滞后的历史中位数”
（`expected_release`），而历史滞后只用决策日可见的首次发布估计，不用未来
日历。观测期结束后仍无发布，绝不会被当成 0 或最终值。

### 2.3 聚合方式

季度目标的连接方式取决于月度指标的 `aggregation`：

- `flow`：季度 = 三个月之和；
- `stock`：季度 = 季末月值；
- `average`：季度 = 三个月均值。

不得跨单位相加；不同 `unit` 的指标只通过各自的标准化增长率进入桥接。

## 3. 模型

### 3.1 总体结构

对目标季度 `T`：

```
目标季度增长率 = w_baseline · 目标自身 AR 基线
               + Σ_i w_i · 桥接预测_i
```

- **基线**：目标自身历史的 AR(1)，不含任何月度指标。
- **桥接**：每个月度指标 `i` 用决策日可见月份计算一个同频增长率，
  经训练期标准化后线性映射到目标增长率。
- **权重**：逆方差加权，带相对下限；结构变化时桥接权重减半。

这是一套“桥接 + 目标自身先验”的混频方案，不依赖第三方库，全部参数
可在小样本下用闭式公式拟合，因此可以逐日重放。

### 3.2 变换与季节

默认 `transform="auto"`：

- 训练截止日可见的目标同比配对 ≥ 12 时用**同比（YoY）**。同比差分本身
  吸收固定季节，不额外估计季节因子；
- 否则退回**环比（QoQ）**，并在增长率上做**加法季节调整**：
  `季节效应_s = 同季节平均增长 − 总体平均增长`。它作用在增长上而不是
  水平上，避免趋势污染季节因子。每个季节位置至少 3 个观测才估计，
  否则不做季节调整并标记。

> 为什么默认同比：在只有 12–20 个季度观测的样本里，季度季节因子本身
> 很难识别；强行估计会让桥接信号失真（本项目对比验证过：在他们身上
> QoQ+季节调整的桥接反而比基线差）。同比把季节问题交给差分，样本要求
> 更低，回测中误差也更小。该选择是事前设定的规则，不按回测结果调整。

月度指标同理：QoQ 口径下做月度加法季节调整，YoY 口径下由同比吸收。

### 3.3 参差发布下的月度缺口

缺报不插值成最终矩阵。对目标季度需要的月份：

1. 已可见月份直接取当时版本；
2. 其余月份从缺口前最后一个可见月**逐月外推**：
   `g_next = c + φ·(g_last − 季节_last) + 季节_next + ε`，
   `level_next = level_last · exp(g_next)`（对数口径）或
   `level_last + g_next`（差分口径）；
3. 缺口之后的观测**不会**被用来回填缺口；
4. 季度聚合只使用三个月齐全的季度（`stock` 除外，只看季末月）。

因此“3 月已结束但 4 月 25 日才发布”的决策日上，3 月仍是 `pending`，
模型用 1–2 月与历史 AR 外推 3 月，并把这部分外推方差计入区间。

### 3.4 识别约束

- 桥接要求目标与指标的完整季度配对 ≥ 8（`min_bridge_pairs`）；
  不足时该指标不进入模型，并写明原因。
- 指标自身月度 AR 要求 ≥ 12 对；不足时退化为随机游走外推并标记。
- 目标增长观测 < 8 时不给正式估计（要么宽区间，要么拒绝）。
- 桥接只支持 1 步（`bridge_max_horizon=1`）：目标季度之前最多一个季度
  没有目标观测。更远期的季度只用目标自身 AR，并明确标记。
- 同比口径下，目标基线随提前步数做 AR 迭代；锚定基期仍是目标季度上一年
  同期（需要该期可见），因此“提前多步”时区间会通过 AR 方差累积变宽。
- 指标最新可见月份比目标季度末早超过 6 个月时，该指标权重置 0。
- 训练截止日的两段均值漂移检验（≥12 个观测、MAD 尺度）只用于放宽
  区间与降低桥接权重，不用于挑选模型。

### 3.5 估计与区间

点估计是各分量增长率的加权和，再还原到水平：

- YoY：`level_T = level_{T-4} · exp(增长率)`；
- QoQ：`level_T = level_last · exp(累计增长率)`。

区间用 Monte Carlo（默认 400 次）合成五类不确定性：

1. **锚定季度修订噪声**：基期季度本身还会被修订，方差来自训练期
   首次→成熟修订的稳健离散度；
2. **目标 AR 创新**：按提前步数累积，含 AR 系数 `(c, φ)` 的参数不确定性；
3. **月度外推误差**：按缺口步数与 AR 方差合成，再按聚合方式折算到季度；
4. **桥接残差与斜率不确定性**：含标准化解释变量的预测方差；
5. **目标版本噪声**：成熟口径加修订噪声；首次发布口径再加“成熟→首次”
   的漂移与噪声。

没有修订历史时用 `fallback_*_sd` 并放宽区间。样本不足、结构变化或没有
桥接分量时，统一按 `wide_inflation=4` 放大区间，并把状态标为 `wide`
（不作为正式估计）。

### 3.6 降级与拒绝

| 情形 | 行为 |
| --- | --- |
| 目标季度已发布 | 状态 `observed_target`，直接返回观测值，不做事后“预测” |
| 没有早于目标的可见历史 / 同比基期不可见 | 状态 `refused`，不给点估计 |
| 目标 AR 不可拟合或增长样本 < 8 | 状态 `wide`，区间放大 |
| 无桥接指标 | 只用目标自身历史，状态 `wide`（除非基线本身足够） |
| 结构变化 | 区间放大、桥接降权，状态 `wide` |

`wide` 与 `refused` 都单独计数，覆盖率只统计真正给出区间的记录，
不会被降级“美化”。

## 4. 修订分解

对同一目标的相邻决策日 `d1 < d2`，点估计从 `V(d1)` 变到 `V(d2)`。
把变动归因到四个来源：

1. `new_data`：d2 才首次可见的**非目标**指标发布；
2. `revisions`：d1 已可见、d2 值发生变化的**非目标**指标发布；
3. `reestimate`：参数由 d1 截止日样本重估为 d2 截止日样本；
4. `target_version`：**目标自身**的可见版本变化（新发布或修订）。

### 4.1 Shapley 约定

对四个来源的 16 个开关组合分别估价（`reestimate` 打开时用该情景自己的
可见资料集合在 d2 截点重拟合；关闭时沿用 d1 参数），取精确 Shapley 值：

```
φ_k = Σ_{S ⊆ F\{k}} |S|!(|F|−|S|−1)!/|F|! · [V(S∪{k}) − V(S)]
```

Shapley 对交互对称，四项严格加总：

```
Σ φ_k = V(全部来源) − V(无来源)
```

### 4.2 链式约定

同时输出固定顺序 `new_data → revisions → reestimate → target_version`
的链式分解。链式增量也严格加总，但交互记在较后加入的来源上。两种
约定都写入输出，交互大小用两两交互项报告：

```
I(a,b) = V({a,b}) − V({a}) − V({b}) + V(∅)
```

### 4.3 不可用情形

任一侧估计被拒绝、目标已观测或全因素情景无法估价时，状态为
`unavailable`/`partial`，缺失情景计数 `missing_scenarios` 单独报告，
**不插补**。两项残差（`residual`、`sequential_residual`）逐次输出，
用于审计加总是否闭合。

## 5. 回测口径

两个口径各自冻结、分别报告，不允许挑有利版本：

- **首次发布值**：`revision == 1` 的值，无论它何时发布；
- **成熟版本**：`revision == 3` 的值。若该季度没有第 3 次修订，
  成熟口径下记为**不可用**，不使用“最后一个版本”替代。

其他冻结项：

- 可见性：`released <= decision_day`；
- 参数：全部由决策日可见版本重估（`fit_day = decision_day`）；
- 区间水平：80%（报告实测覆盖率与平均宽度）；
- 目标已发布：跳过，不做事后预测；
- 基线：同一目标自身历史（AR + 目标自身季节/修订处理），只关闭月度
  桥接，避免把基线故意做差。

报告给出：

- 两个口径的 MAE / RMSE / 偏差 / MAPE / 覆盖率 / 平均宽度；
- 宽度相对基线的比值（同口径、同记录集合）；
- 按提前期分组的误差与覆盖率；
- 正式估计子集（`status=ok`）的指标，与 `wide`/`refused` 计数分开。

多步与修订影响：区间模拟显式包含提前步数带来的 AR 方差累积、月度缺口
外推方差与目标版本修订噪声；`mature` 口径的区间比 `first_release` 更窄，
因为前者不含“成熟→首次”漂移。

## 6. 重放与审计

每个决策日的 `replay` 记录（`python -m nowcast_data.cli replay`）包含：

- 决策日、目标、可见性规则；
- 每个资料单元的状态、当时值、版本号、发布日期；
- 逐条实际取用的 `release_id`、修订序号、发布日与值；
- 目标指标在决策日路径上的全部版本；
- 输入摘要 `inputs_digest`（对可见版本集合做 SHA-256）。

`docs/report.json` 里的 `replay_sample` 为控制体积只保留目标季度相关的
单元，完整记录用 `replay` 子命令生成。

因此别人可以只凭登记资料与决策日重算出同一结果；发布日历
（`calendar` 子命令）列出每个指标每次实际发布、首发布滞后中位数与最大值。

## 7. 合成资料的覆盖场景

`data/realtime.json` 由 `tools/make_realtime_data.py` 以固定种子生成，
仅用于演示模块行为，不代表任何现实机构数据。它刻意包含：

- **延迟发布**：`ind_prod 2023-05` 首次发布推迟到期末后 75 天；
- **历史大修订**：`GDP 2024-Q3` 首次发布偏低 6%，第三次修订回到真值；
  `ind_prod 2024-02` 首次发布偏高 15%；
- **月末跨季度**：`2023-03` 月度资料在 2023-04-25 发布，决策日覆盖
  3-31、4-1、4-26；
- **整列长期缺报**：`ind_price` 2022 全年无发布；`ind_prod` 2020-04
  至 2020-06 连续三个月无发布；
- **已报告为零**：`ind_orders 2023-06` 发布值就是 0；
- **成熟版本缺失**：`2025-Q4` 只有两次修订，成熟口径不可评估；
- **首次发布延迟**：`2024-Q1` 目标首次发布额外推迟 30 天。

生成过程刻意加入“当季共享冲击”：它影响当月与当季目标，但目标自身
历史看不到。这正是实时监测相对纯目标基线的信息优势来源；如果合成
数据里没有这种结构，桥接不可能在事前赢过基线。

## 8. 已知局限

- 桥接是线性单变量回归，不做因子模型或卡尔曼滤波；样本更充足时
  状态空间方法可能更有效，但当前资料量不支持稳定估计。
- 季节调整是加法、固定效应式，不随时间变化；结构变化只通过放宽区间
  与降权体现，不做时变季节。
- 修订过程用“首次→成熟”的稳健漂移与离散度概括，不建模逐次修订路径。
- 月度缺口的 AR 外推是单变量、常数参数；缺口很长时区间会明显变宽，
  这是有意保守。
- 合成资料的相关结构是人为设定的；真实资料上桥接增益需要用同样的
  冻结回测重新验证，不能直接引用本报告的数值。
